# Changelog

## Application changes from [Round Weather Display](https://github.com/Canterrain/round-weather-display) by Josh Hendrickson

- Added an audible alarm with one-time and weekday repeats, sound previews, gradual ringing volume, Snooze, Slide to Dismiss and restart recovery, with optimized sound generation for preview and ringing.
- Added Sound Machine with nine looping recordings, three generated noises, independent volume and sleep timers. Improved playback buffering across recording repeats.
- Added optional DS3231 backup time and locally calculated Sunset to Sunrise Night Shift, with separate Day/Night brightness and remembered appearance.
- Added Visual Crossing alongside Open-Meteo, expanded weather-picture mappings, dated five-day forecasts and concise waiting/stale-weather notices.
- Added National Weather Service watches and warnings with alert lists, details and optional sounds, replacing the former threshold-based storm checks.
- Added full-screen U.S. Radar from RainViewer and USGS, covering 75 miles with smoothed precipitation edges and a Light/Moderate/Heavy key; it replaces Conditions in device navigation.
- Reworked touchscreen settings to the approved design, including visible keyboard inputs, live Display Save and an immediate Alarm On/Off switch.
- Simplified application ownership and removed superseded screen experiments and routine clock-footer messages. Retired the unused Conditions screen and its dedicated artwork, mockup and calculations.
- Improved memory placement, weather scheduling and drawing efficiency while preserving approved appearance and behavior.

See the [user guide](README.md) for current features and source credits. Product behavior is defined in [the architecture](docs/architecture.md).
